# Stave

Photograph a bow on the tiller tree and see where to scrape. Runs entirely on the phone (Python via Pyodide); photos never leave the device.

Fonts: Big Shoulders Text and Archivo, SIL Open Font License (vendor/fonts/). Pyodide 0.28.3 (MPL-2.0) with NumPy, SciPy, Pillow, OpenBLAS under their own licences (vendor/pyodide/).
